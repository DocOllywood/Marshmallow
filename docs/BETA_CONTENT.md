# Beta content engine

Human-operated inspiration only. These examples are **fictional / generic**. Do not seed defamatory or unverified claims. Do not treat this file as production copy.

A good Marshmallow creates two desires: I want to answer this, and I really want to know what the other players chose.

Default format: **binary Quick**. Helper: open now / close 3m / target reveal 4m / hard 10m. Minimum sample 5.

## Recommended first-night set

### Before the session

- **6 Quick** in one Quick Set (3 promoted + 3 queued; extras optional)
- **1 Daily** for today’s UTC date
- Kitchen TEST SESSION: promoted pool ≈ 3, queued behind them, Daily = 1
- Confirm Email off. Email sending off.

Suggested set name: `Friday Night Reality`

### 0–10 minutes

Players chain Quick. PLAY ANOTHER after each seal.

### ~3–10 minutes

Target reveals begin. If sample < 5, Still cooking. Keep chaining.

### Later

Daily is the delayed-return test. No Quick email or inbox Reveal Ready.

### After

Review Kitchen:

- Quick seal rate
- Quick continuation
- Quick sample size / sample health
- First payoff (from `result_available_at`)
- Daily RRR later
- Shares
- Feedback
